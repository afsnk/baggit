---
title: Verify checkout
description: Verify payment status of a checkout transaction
---

`GET /v1/checkout/${orderId}/verify{:sh}` endpoint returns the order status found with its corresponding `orderId{:sh}`.
Call this endpoint after a redirect back to your `redirectUrl{:sh}` from the `POST /v1/checkout{:sh}` checkout creation endpoint.

### Example request
```sh tab="cURL"
curl -L \
  --request GET \
  --url 'https://api.baggit.link/v1/checkout/{orderId}/verify' \
  --header 'Baggit-Secret-Key: '"$BAGGIT_SK" \
  --header 'Content-Type: application/json' \
```

```ts tab="NodeJS"
const res = await fetch('https://api.baggit.link/v1/checkout/{orderId}/verify', {
  method: 'GET',
  headers: {
    'Baggit-Secret-Key': process.env.BAGGIT_SK,
    'Content-Type': 'application/json'
  }
});

const data = await res.json();
console.log(`Checkout verification response: ${data}`);
```
